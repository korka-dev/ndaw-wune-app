# Sons de notification vocale — Ndaw Wune

Déposer ici vos 2 fichiers audio WAV :

## alerte_30min.wav
Message à enregistrer :
"Êtes-vous prêt ? Votre programme commence dans 30 minutes. Préparez votre matériel !"

## alerte_5min.wav
Message à enregistrer :
"Attention ! Votre cours commence dans 5 minutes. Il est temps de commencer !"

## Format requis
- Format : WAV (ou MP3)
- Mono ou Stéréo
- 44 100 Hz recommandé
- Durée : 3 à 8 secondes max

Après avoir déposé les fichiers, rebuilder l'APK : `expo run:android`
